Gestures

Gesture	                              Action
---------------------------------------------
Move index finger	                      Move pointer
Quick thumb-index pinch	                Click
Hold pinch for 0.35 seconds	            Start dragging
Release pinch	                          Drop/release mouse
Index and middle raised, others folded	Scroll
Closed fist held for 1 second	          Close active window with Alt+F4
Q	                                      Stop the program
